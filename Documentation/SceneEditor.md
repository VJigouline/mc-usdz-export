# Using it in SceneEditor

[SceneEditor](https://github.com/VJigouline/SceneEditor) saves scenes with mc-usdz-export from the **Scene** tab: choose the format under **Select output format**, then **Save Scene**. The **USDZ for AR Quick Look (usdz)** format writes a package that iPhones and iPads open in AR, and that SceneEditor opens again.

The transform gizmo and light helpers are left out. Warnings, such as objects the format can't hold, go to the browser console, and a scene that can't be saved gives a **Failure** message.
